A full-featured social media web application built with Django that allows users to connect, chat, and share their profiles — inspired by the functionality and design of modern platforms like Instagram.
User Management

Secure user authentication (signup, login, logout).

Profile management: upload profile picture, update name and address.

Friend system:

Send, cancel, and accept friend requests.

View friend lists and pending requests.
Post text, images, or updates.

Like, comment, or delete your own posts.
Frontend:

HTML5, CSS3, JavaScript

Bootstrap / TailwindCSS (for responsive UI)

Backend:

Django (Python)

Django ORM for database interactions

Database:

SQLite (development)

Other Tools:

Django Channels 

Pillow (for image uploads)
